
# 🧪 ChemLab Virtual Laboratory

An interactive chemoinformatics platform for molecular visualization and chemical descriptor analysis.

**Developer:** Sanjey Barathi M I  
**Program:** Artificial Intelligence and Machine Learning (AI & ML)

## 🚀 Live Demo

[**Open ChemLab Virtual Laboratory**]

## ✨ Features

- Molecular database and SMILES input
- 2D molecular structure generation
- Interactive 3D molecular visualization
- Ball-and-stick, stick, space-filling and wireframe models
- Molecular descriptor calculations
- Molecular comparison charts
- Assessments and downloadable reports
