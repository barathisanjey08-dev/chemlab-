# ChemLab — Interactive Chemoinformatics Virtual Laboratory

A Streamlit educational project featuring RDKit-based SMILES validation, 2D molecular diagrams, calculated molecular descriptors, 3D conformer generation, an interactive 3Dmol.js viewer, molecule comparison, fingerprint similarity, assessment, and downloadable reports.

**Developed by:** Sanjey Barathi M I  
**Program:** Student of Artificial Intelligence and Machine Learning (AI & ML)

## Features

- Built-in example molecules: water, methane, ethanol, benzene, phenol, acetic acid, aspirin, caffeine, glucose, and paracetamol.
- Validate custom SMILES.
- Generate 2D structures using RDKit.
- Generate 3D conformers using RDKit ETKDG and optimize with MMFF or UFF when supported.
- Rotate and zoom 3D models in a 3Dmol.js viewer.
- Display molecular formula, molecular weight, TPSA, estimated LogP, atom counts, rings, H-bond donors/acceptors, and more.
- Compare molecular properties and Morgan fingerprint similarity.
- Complete a 10-question assessment.
- Export molecular descriptors as CSV and a PDF report.

## Run locally

Python 3.11 is a good starting point. Create a virtual environment, then run:

```bash
python -m venv .venv
```

Activate it:

- Windows: `.venv\Scripts\activate`
- macOS/Linux: `source .venv/bin/activate`

Install dependencies and start Streamlit:

```bash
pip install -r requirements.txt
streamlit run app.py
```

RDKit package availability depends on the Python version and platform. If installation fails, use a supported Python version or install RDKit through conda-forge, then install the remaining requirements.

## Deploy on Streamlit Community Cloud

1. Create a GitHub repository and upload `app.py`, `requirements.txt`, and `README.md`.
2. Visit https://share.streamlit.io/ and sign in with GitHub.
3. Choose **Create app** and select your repository.
4. Set the main file path to `app.py`.
5. Deploy.

The 3D viewer loads 3Dmol.js from its public CDN, so the browser needs internet access for the interactive 3D component. The molecular 3D coordinates are generated by RDKit on the Python side.

## Notes and limitations

- The 3D view shows a computationally generated conformer, not necessarily an experimentally observed structure or the only possible conformer.
- LogP is an estimate. Computed descriptors are not experimental measurements.
- Chemical examples are educational and not medical advice.
- Custom structures may fail 3D generation if RDKit cannot find a valid conformer. The app reports this instead of claiming success.
